# Data types in Python: There are various data types in Python but we mainly study followings:
# 1. Primitive data types: These are data types which stores only one value in a variable. It uses a small fixed amount of memory.

# i. Integers: We can have -ve, zero, and +ve values in Integer data type. e.g.

quantity = 240
print(quantity)

volume = 0
print(volume)

profit = -12
print(profit)

# ii. String: Anything written in "" or '' or '''''' is treated as String data type but we will mostly use "". e.g.

quality = 'satisfactory'
print(quality)

status = "OK Tested"
print(status)

release = '''29th July 2026'''
print(release)

release2 = """21st December 2026"""
print(release2)

# iii. Float: All decimal values are treated as Float data type. e.g.

area = 12.55
print(area)

quantity = 0.0
print(quantity)

stockPrice = -1.2
print(stockPrice)

# iv. Boolean: It holds only two values i.e. either True or "False", make sure while writing True or False use capital T and capital F or else it will throw error. e.g.

isAvailable = True
print(isAvailable)

isValid = False
print(isValid)

# v. None: This is assigned to those variables where we don't want to store any value currently. e.g.

none = None
print(none)


# 2. Non-primitive data type: Also known as Derived data type. These can hold multiple values in a single variable. It uses variable amount of memory.

# i. list: An ordered, mutable sequence of items that allows duplicate elements and is written in []. This is equivalent to writing and array in JS. e.g.

list = [1, 2, "apple"]
print(list)

# ii. tuple: An ordered, immutable sequence of items that allows duplicate elements and is written in (). e.g.

tuple = (10, 20, 30)
print(tuple)

# iii. dict: This stands for Dictionary. It is an un-ordered, mutable collection of key-value pairs and is written in {}. This is equivalent to writing JSON in JS. e.g.

dict = {"name": "Alice", "age": 25}
print(dict)

# iv. set: It is an unordered collection of unique, items that does not allow duplicates. Set itself is mutable, however, the elements stored inside a set must be immutable meaning, we can store all immutable data types in Set but we cannot store mutable data types in Set such as List and Dictionary. It is also written in {}.

set = {1, 2, 3}
print(set)

=> Even Classes and Objects are also considered as non-primitive data type in Python.

# Type Conversion: This means converting one data type into another. There are two types:

1. Conversion: This happens automatically in Python. In Java this is known as Implicit conversion (Widening Casting). e.g. Let us consider we want to add to variables as shown below:

b = 4.25  # This is Float value.

sum = a + b
# Sum will automatically convert into Float value because Float is superior than Integer as it can store more information i.e. the decimal values too.

2. Casting: This is done manually by developers. In Java this is known as Explicit conversion (Narrow Casting). e.g. Let us consider we want to add to variables as shown below:

a = "2"  # This is String value.
b = 4.25  # This is Float value.

sum = a + b
# Sum will throw error as it cannot directly convert result into different data type so, we need to manually convert String into Integer or Float. It will throw TypeError: can only concatenate str (not "float") to str.
print(sum)

After Casting:
a = int("2")  # Converting String into Integer.
b = 4.25  # This is Float value.

print(type(a))
sum = a + b
print(sum)

OR, We can also convert it into Float value.
a = float("2")  # Converting Sting into Float.
print(type(a))

=> But if character were present instead of number inside a String then we can not do type casting, if we try then it will throw error as, characters can not be converted into Integer or Float.

Other e.g.

a = str(a) # Converting Float into String

print(type(a))

# Indexing: When a string is created in Python then each character in a string gets its index value i.e. the position of that particular character. Just like in all other programming language in Python also indexing starts with zero.

=> Why do we need indexing?
Because it helps us to access individual character's of a string. e.g.

str = "Jain University"
ch = str[0]
print(ch)
print(str[6])

Note: With the help of index you can only access characters but cannot modify it because Strings are immutable i.e. once created cannot be modified.


# Slicing: It means accessing specific part of a string. It can be done by: stringName[startingIndex : endingIndex] where endingIndex is exclusive. e.g.

str = "Jain University"
print(str[1:4])

=> If you want to access from startingIndex all the way up to the end of the string then you pass endingIndex + 1 or, you can also use len(str) instead of endingIndex or, also you can avoid passing endingIndex i.e. Python automatically assumes that you want to go all the way up to the end of the string. e.g. are shown below.

print(str[1:4])
print(str[5:15])
print(str[5 : len(str)])
print(str[5:])

=> Similarly, if you miss passing startingIndex then Python automatically assumes that you want to start from zeroth index. e.g.

print(str[:7])

=> Also, Python supports -ve index slicing which is not available in other programming languages. Basically -ve indexing means you want start counting from len(str) i.e. from backside of the string. e.g.

print(str[-3:-1])  # Here also endingIndex is exclusive.

=> For e.g. there are lot of conditions like we can apply for driving license only if our age is 18 or above or on our marks which has grading like if our marks is 90 and above then we will get grade A and so on. All these conditions can also be be expressed in code too.

=> In Python to express the conditions we use:
1. if
2. if...else
3. elif

    statement1
elif condition:
    statement2
else:
    statementN

If we use if conditions then all if will get executed. Whereas, elif will come into picture only if, given if condition does not satisfy which brings us into conclusion that for writing elif we have to mandatorily write if. e.g.

    print("Number is greater than 3")

=> Although nesting is not recommended, if we are nesting then also we should not go more than 2-levels of nesting, as that makes code more complicate to understand and debug. In order to avoid nesting we can use logical operators.

e.g. for nesting:

    if age >= 80:
        print("You cannot drive")
    else:

else:
    print("You cannot drive")

age = 79

# Here we are trying to validate whether the age is 80 >= age >= 18.

1. Lists in Python: It is a built-in data type that stores set of values. It can store elements of different types i.e. we can store different data types in a single list whereas other program languages does not allow you to do this.

Lets say if we want to store marks of students in a class then we have to create variables equal to number of students in that class which will make coding very much time consuming and tracking those variables would also be very difficult. e.g.

marks1 = 45

=> In order to simplify this Python provides an in-built data type called as list where we can stored multiple values in a single variable as shown below:

=> A list has it own syntax as you can see above and it has so many properties and methods which are similar to String properties and methods, also we can print list and check its type as shown below.

# Set in Python: It is an unordered collection of unique, items that does not allow duplicates. Set itself is mutable, however, the elements stored inside a set must be immutable meaning, we can store all immutable data types in Set but we cannot store mutable data types in Set such as List and Dictionary as well as Set itself. => Unlike dictionary, a set only stores values in it not key: value pair. In case of duplicate values in set it ignores duplicates while printing. And also we can check the length of a set and even this len() method also ignores duplicates values. e.g.

# Set Methods:

1. add(): Adds an element in a set. e.g.

=> We can add other data types too in set but it should be immutable. e.g. adding Tuple in set.

=> But, if we try to add List in set it will throw TypeError: cannot use 'list' as a set element (unhashable type: 'list') here, unhashable type means data types whose elements / values can change be changed and if element / values are changing then their hash value keeps on changing which is not acceptable by Set. e.g.

set.add([9, 8, 7])
print(set)

2. remove(): Removes an element from set. e.g.

print(set)

set.remove("Kawasaki Ninja H2R") # Since this item does not exist in set it will throw "KeyError", this indicates thats the key and values are same in set.

4. pop(): It removes a random element from the set. e.g.

=> Its use case is that if we want to generate a random value from unique elements then we can use this.

print(set1) # Here, there is not change in set1 and,

6. intersection(): It combines common values of two sets and returns a new Set. e.g.

print(set1.intersection(set2))

    print(i)

    print(i)

# Default parameters: Let's consider a case where a user defines a function with parameters (a,b) but while calling he/she is not passing any arguments or passing only one arguments then we will get TypeError: calcProd() missing 2 required positional arguments: 'a' and 'b'. e.g.

# Recursion in Python: When a function calls itself repeatedly is called as recursion. It works like a loop you can say it is an alternative for loop as whatever can be done with loop can also be done with recursion too and vice-versa. But in some cases we prefer loop and some places we prefer recursion. e.g.

def printNum(n):
    # Base case (aka terminating condition for recursion). It is mandatory or else infinite recursion will happen.
    if n == 0:
        return

    print(n) # Work done
    printNum(n - 1)  # Recursion (A function calling itself) / Recursive call

printNum(5)  # Function call

Other e.g. Returning a factorial of n using recursion.

def printFact(n):
    if n == 0 or n == 1:
        return 1
    else:
        return n * printFact(n - 1)

print(printFact(6))

# Open, read and close file operations:
For this we use built-in function of Python.

Syntax:
    f = open("file_name", "mode")
    # Here the file name should be complete i.e. along with extension like sample.txt, demo.docx.
    # mode has to be passed i.e. r: read mode meaning, we are just going to read the file or w: write mode meaning, we are going to make some changes in the file. If we don't pass any mode then bu default Python assumes we are going to read the file.

e.g. Lets create a file name demo.txt and put some data in it and then we will try to do some operations on it.

f = open("demo.txt", "r")  # This is how you open a file in read mode.

# The above line can also be written as:

print(data)  # Printing the data of the file.
print(type(data))  # Looking for what type of data is stored in the file.

f.close()  # Closing the file after use.

=> Now, there are various modes present in the file mode lets take about some of the modes.
1. "r" => open file for reading (default).
2. "w" => open file for writing, truncating the file first, meaning, first all data of the file is deleted and then new data is added.
3. "x" => creating a new file and opening it for writing.
4. "a" => open file for writing, appending to the end of the file if it exists meaning, without deleting the old data in the file and simply add new data. (We will talk about this in a while)
5. "b" => opens the file in binary mode.
6. "t" => opens the file in text mode.
7. "+" => open a disk file for updating (reading and writing) i.e. if we write "r+" that means we want to read as well as write in the file, similarly "w+" means we want to write as well as read the file and so on.

=> Now, if you have noticed in our previous example then we have not mentioned "t" in the mode because by default the file is opened in text mode only. If you want to open the file in binary mode then you have to combine two modes together as shown below.

f = open("demo.txt", "rb")  # This is how you open a file in binary-read mode.

print(data)

f.close()

Putting content after truncate
